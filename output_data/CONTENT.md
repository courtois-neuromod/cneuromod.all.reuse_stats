# Output Data

Generated by `invoke run`:

- `cneuromod_citations.csv`: papers using CNeuroMod data, counted by year and publication type. Columns: `year` (empty for undated entries), `type` (`Journal`, `Preprint`, `Conference`, `Thesis`, `Book Chapter`, `Other`), `count`. Produced by `run-citations` from `cneuromod_references.bib`.
- `figures/panel_sizes.json`: each montage panel's placed size in mm, read from `figure_montage.svg`. Produced by `run-figure-layout` on every run.
- `figures/cneuromod_citations/citations_by_year.png`: stacked bar chart of those papers by year and type. Undated entries are left out. Produced by `notebooks/cneuromod_citations.ipynb` at the panel's montage size and DPI.
- `figure_montage.png`: the composed figure. Produced by `compose-figure` (needs Inkscape).
- `PROVENANCE.json`: written by `run`. Records the git commit, environment, inputs consumed, and a checksum per output. Git-tracked; it changes on every run.

Hand-authored, not generated:

- `figure_montage.svg`: the montage layout, edited in Inkscape. It is the single source of truth for panel sizes.

See `source_data/CONTENT.md` for inputs.
